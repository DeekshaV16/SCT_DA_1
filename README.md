# SCT_DA_1
**Excel Sales Dashboard using Superstore Sales Dataset - SkillCraft Technology Data Analyst Internship Task 1**

**Project Overview**
Created an interactive Sales Dashboard using the Superstore Sales Dataset in Google Sheets.

**Features**
a) Total Sales Analysis
b) sales by Category and Region
c) Sales Trends Over Time
d) Conditional Formatting for High/Low Performers

**Tools Used**
Google Sheets
Pivot Tables
Pivot Charts
Conditional Formatting
